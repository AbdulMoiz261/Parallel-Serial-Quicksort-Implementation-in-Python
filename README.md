# Parallel vs Serial Quicksort Implementation in Python

This repository demonstrates the implementation and performance comparison of **Serial** and **Parallel** Quicksort algorithms using Python. It highlights the execution time differences across various data sizes and visualizes the results with Matplotlib.

---

## 📁 Repository Contents

| File Name                     | Description |
|------------------------------|-------------|
| `Serial.py`                  | Implements standard recursive Quicksort with execution time measurement and plotting. |
| `Parallel.py`                | Implements parallel Quicksort using `multiprocessing` to improve performance on large datasets. |
| `Comparison.py`              | Generates a combined performance graph comparing serial and parallel implementations. |
| `Output Of Serial.pdf`       | Plot showing Serial Quicksort performance. |
| `Output Of Parallel.pdf`     | Plot showing Parallel Quicksort performance. |
| `Output Of Comparision.pdf`  | Plot comparing Serial vs Parallel Quicksort. |
| `Project Report.pdf`         | Complete report detailing the methodology, implementation, and results. |
| `PDC Project Proposal.pdf`   | Initial project proposal document. |
| `README.md`                  | Documentation for the repository. |
